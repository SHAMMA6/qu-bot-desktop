### Description — full (project page)

> QU Bot is a desktop companion, not a widget. A solid vector blob with two
> expressive eyes floats above your desktop, drifts toward whatever you are
> pointing at, docks into the title bar of the window in front and rides along
> when you drag it, dodges when you swipe at it, and follows you to your second
> monitor.
>
> It has 78 emotions, and each one is a complete performance — its own eye
> geometry, breathing rate, posture, blink rhythm, gaze behaviour and particle
> effect. You cannot pick them: what it feels is reached by weight from mood,
> energy, boredom, affection and personality, and from what you are actually
> doing at the keyboard.
>
> Four slow meters and a set of lifetime counters are written to disk, so the
> mascot that greets you tomorrow is the one you had today, with the same
> opinion of you. On top of that it runs focus mode, a work clock that only
> advances while you are really at the keys, persistent timers and pomodoro, and
> it will hold files you drop on it.
>
> The whole interface ships in English and Arabic — 319 strings and 73 buckets
> of dialogue in each, with the settings window laid out right-to-left in Arabic.
> A missing or malformed translation fails the test suite rather than reaching a
> reader. One GitHub Actions run builds and publishes Windows, macOS and Linux
> artifacts together with the auto-update feed, so installed copies pick up a new
> version within six hours.

These filenames carry the version, so a link like
`releases/latest/download/QU-Bot-Setup.exe` will **not** work — the table above
has to be updated each release, or the button below has to resolve it at runtime.

### A download button that never needs updating

Drop this into the portfolio project page. It asks GitHub for the newest release,
picks the right file for the visitor's OS, and falls back to the releases page if
the request fails.

```js
const REPO = 'SHAMMA6/qu-bot-desktop';
const FALLBACK = `https://github.com/${REPO}/releases/latest`;

// Order matters: the first pattern that matches an asset name wins.
const PICK = {
  win: [/-Setup\.exe$/, /-portable\.exe$/],
  mac: [/arm64-mac\.zip$/, /-mac\.dmg$/],
  linux: [/\.AppImage$/],
};

function platform() {
  const ua = navigator.userAgent;
  if (/Win/i.test(ua)) return 'win';
  if (/Mac/i.test(ua)) return 'mac';
  return 'linux';
}

export async function latestDownload() {
  try {
    const res = await fetch(`https://api.github.com/repos/${REPO}/releases/latest`);
    if (!res.ok) return { url: FALLBACK, version: null };

    const release = await res.json();
    const assets = release.assets ?? [];
    for (const pattern of PICK[platform()]) {
      const hit = assets.find((a) => pattern.test(a.name));
      if (hit) return { url: hit.browser_download_url, version: release.tag_name };
    }
    return { url: FALLBACK, version: release.tag_name };
  } catch {
    return { url: FALLBACK, version: null };
  }
}
```

```jsx
const [dl, setDl] = useState({ url: FALLBACK, version: null });
useEffect(() => { latestDownload().then(setDl); }, []);

<a href={dl.url} className="...">
  Download QU Bot{dl.version ? ` ${dl.version}` : ''}
</a>
```

### Worth saying on the download page

The builds are not code-signed, so Windows shows SmartScreen's *"Windows
protected your PC"* on first launch — **More info → Run anyway**. On macOS and
Linux everything works except *Notice the app in front*, which needs a
Windows-only helper and simply stays off.
